# Archivio Versione WhatsApp Classic (v1.6.0)

Questo archivio contiene l'interfaccia originale completa di **"Dove lo AI messo"** con design **WhatsApp al 100%** (v1.6.0), antecedente all'introduzione del design Olivetti Industrial.

- **Branch Git dedicato**: `whatsapp-classic`
- **Tag Git dedicato**: `v1.6.0-whatsapp-classic`
- **File HTML autonomo**: [`index.html`](index.html)

### Come tornare alla versione WhatsApp Classic:
1. **Via Git (consigliato per ripristino completo)**:
   ```bash
   git checkout whatsapp-classic
   ```
2. **Oppure sostituendo semplicemente il frontend**:
   ```bash
   cp archive/whatsapp_classic/index.html index.html
   ```
