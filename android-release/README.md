# Dove lo AI messo — Android Releases (OTA)

Questo faldone contiene l'ultimo file APK compilato e il file descrittivo dei metadati per gli aggiornamenti automatici Over-The-Air (OTA).

## File
* `app-debug.apk`: L'applicazione Android compilata pronta all'installazione su smartphone (incluso Google Pixel 9).
* `version.json`: Metadati di versione utilizzati dall'app per rilevare gli aggiornamenti in tempo reale su GitHub all'avvio.

## Download Diretto
* **Download APK**: [app-debug.apk](https://raw.githubusercontent.com/themeig/DOVE-LO-AI-MESSO/main/android-release/app-debug.apk)
* **Metadati Versione**: [version.json](https://raw.githubusercontent.com/themeig/DOVE-LO-AI-MESSO/main/android-release/version.json)
